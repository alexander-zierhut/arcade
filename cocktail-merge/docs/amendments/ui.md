## 5.2 Boot guard

Add these sentinels to `CHECKS` (after `src/art/sprites.js`, `src/render/fx.js` and `src/audio/sounds.js`):

```js
['src/art/backgrounds.js', function () { return f(CM.art.backgrounds.pick); }],
['src/render/fxdraw.js', function () { return f(CM.render.fxdraw.rays); }],
['src/render/guides.js', function () { return f(CM.render.guides.aim); }],
['src/audio/music.js',   function () { return f(CM.audio.music.setEnabled); }],
```

The backgrounds sentinel checks only `pick`, the one function both the keyed API of the task brief and the
current-scene API that `src/art/backgrounds.js` actually ships (`start`, `setScene`, `current`, `credits`, `paint`)
have in common.

Add: "On failure the guard empties `body`, sets `body.className = 'boot-failed'` and appends the card
(`.boot-card`, styled in base.css). On success it calls `CM.main.boot()` inside a try/catch; a throw shows the same
card with `src/main.js (boot failed: <message>)`. `boot()` is idempotent (main.js may also auto-boot)."

## 5.5 CM.ui

Replace the CM.ui block with:

- `init(handlers)`. `handlers` = `{ onPlay, onContinue, onNewGame, onResume, onRestart, onQuit, onKeepPlaying,
  onPlayAgain, onTitle, onPause, onToggleMute, onToggleMusic, onToggleAmbience, onToggleNumbers, onToggleRelaxed }`.
  - The `onToggleX(value)` handlers receive the **new value of the Save field** (`onToggleMute(muted)`,
    `onToggleMusic(music)`, …). The UI re-reads `CM.app.ctx.save` afterwards to draw the switches.
  - `onPlayAgain` (Game over "Play Again", Enter, R) falls back to `onNewGame`. `onTitle` (Game over and OOPS
    "Title", Esc in Game over) falls back to `onQuit`. `onPause` (the HUD Pause button) falls back to
    `CM.app.ctx.intents.pause('button')`.
  - The armed confirmation is done by the UI: the app's `onRestart` / `onNewGame` start a game immediately.
  - Idempotent: a second call only swaps the handlers. It also binds the HUD buttons.
- `showOverlay(id | null, data?)`, `id` ∈ `'title' | 'pause' | 'win' | 'over' | 'oops' | 'rotate'`. `data`
  (every field optional, missing values come from `CM.app.ctx`): title `{ save, run: RunRecord | null }`
  (Continue shows `run.game.score`; New Game is armed when it is > 0); pause `{ score }`; win and over
  `{ score, best, newBest, highestTier }`.
- `toast(text, tier)` [**hud.js**, moved from overlays.js to keep overlays.js under 400 lines; same API].
- `setHud(game, save)`: diffed, safe to call every frame. It also shows "NEW BEST!" the first time
  `score > ctx.bestAtRunStart > 0` and then sets `CM.app.ctx.newBestShown = true` (so the app need not).
- `setHudVisible(b)`, `consume(events, game)`, `notReady()` (plays `CM.audio.notReady()` and calls
  `CM.render.fx.notReady()` or `CM.render.notReady()` when present).
- Helpers (not in rev 3): `applyLayout(lay)` [hud.js] positions HUD, strip, toasts and the title column (also
  picked up automatically when `CM.app.ctx.lay` changes); `setMuteIcons(muted)`; `refreshSettings()`;
  `keyAction(code) → boolean` [overlays.js] (the overlay keys outside PLAY, called by input.js); `armRestart()`;
  `current() → id | null`; `openSheet('howto' | 'settings' | 'collection')`, `closeSheet()`; `tierName(t)`, `fmt(n)`.
- `storage.load/save/loadRun/saveRun/clearRun` as before, plus `storage.persistent() → boolean`. `loadRun()`
  discards a record whose `v !== 1`, `rulesVersion !== RULES_VERSION`, or that lacks `game` or `meta`.
- `input.attach(inputLayer, getLayout, getView, intents)`; `intents.pause(key)` gets `'esc' | 'p' | 'button'`
  (Esc in OVER_MENU goes to the title, P does not). The input layer sets `intents.cancel` (boolean) while a
  gesture is in the cancel state; `input.cancelling() → boolean` and `input.active() → boolean` expose the same
  thing to the renderer. `heldDir`, `precise`, `reset`, `guardUntil` as before.

**Dispatch order (5.7):** `ui.consume` must run **before** the save logic ORs a `discover` into
`save.discovered`, because the toast reads the persisted mask to choose between "NEW: X!" and
"NEW COCKTAIL: X!".

## 3.5 Overlays (changes)

- **Title**, child order: tag, logo, icon row, buttons, stats, how-to card, **chip row** ("How to play",
  "Collection", "Settings"; 44 px cream chips), **art credit**. The icon row is a button that opens the
  Collection sheet (3×3 grid as in Pause, plus "N of 9 cocktails discovered").
  - The "How to play" chip appears when the how-to card is hidden: when `H < 700` **or** when the column would
    overflow. If it still overflows, the column gets the class `compact`: smaller logo (`clamp(30px, 10vw, 44px)`),
    tag text from 17 px, 6 px child margins, smaller chips. As a last resort it scrolls.
  - The column starts at the roof hem `max(safeTop, 7% H)`, and its top padding puts the tag at
    `max(9% H, safeTop + 8)` as before. The ribbon runs from the hem to the clothespin (its height is measured),
    and the swing pivots at the ribbon top.
  - Tag width `min(80%, 340px, column − 92px)`, so the title's Mute button never covers the card.
  - The logo stays on one line; JS shrinks it in 2-px steps, down to 28 px.
  - Stats: "Best: N · Highest: X" (parts never break inside), then "Sangrias mixed: N" when wins > 0.
  - Credit (13 px, cream on a dark shadow): "Beach 2D Backgrounds by CraftPix.net (craftpix.net), OGA-BY 3.0", plus
    any other credit from `CM.art.backgrounds.creditLine(key)` or `credits()` that is not a CraftPix line. Its
    segments never break inside "OGA-BY 3.0".
- **Settings sheet** (title) and **Pause** toggles: "Sound", "**Music**", "Ambience", "Relaxed table" (note
  "applies to the next game"), "Show tier numbers". The Settings sheet repeats the credit line.
- **Focus.** Overlays focus their primary button only on fine pointers (no stray focus ring on phones).
- **Ghost taps.** Overlay buttons ignore activations within `APP.INPUT_GUARD_MS` (250 ms) after an overlay or sheet
  opens.
- **Reduced motion.** Swing, bob, sunburst, jug rock, rotating phone, armed pulse, coin spin, pill bump and slot
  pulse are off; cards and toasts only fade.
